# 素材放这里

## 鱼（必须按编号命名）

放在 `assets/fish/` 下，**两位编号 + `.webp`**（WebP 比 PNG 小 4~5 倍，首屏快；想用 PNG 就把 `src/config.js` 里 `assetExt` 改成 `'.png'`）：

| 文件 | 等级 | 名字 | 说明 | 当前尺寸 |
|---|---|---|---|---|
| `00.webp` | 0 | 鱼子 | 最小，最先掉落 | 384 |
| `01.webp` | 1 | 小鱼苗 | | 384 |
| `02.webp` | 2 | 小金鱼 | | 384 |
| `03.webp` | 3 | 河豚 | | 384 |
| `04.webp` | 4 | 鲳鱼 | 掉落池最大就到这级 | 384 |
| `05.webp` | 5 | 鲈鱼 | | 384 |
| `06.webp` | 6 | 鲑鱼 | | 384 |
| `07.webp` | 7 | 鲨鱼 | | 384 |
| `08.webp` | 8 | 鲸鱼 | | 384 |
| `09.webp` | 9 | 小鲸鱼娘 | | 384 |
| `10.webp` | 10 | 蓝色大肥鱼 | 终级，两条相撞会炸 | 384 |

尺寸单位是像素；屏幕上的实际大小由 `src/config.js` 里的 `r` 决定。图片**按原样绘制**（透明的地方就是真实轮廓，不再裁圆）。

## 背景

- `assets/bg.png` —— **底图**（深海渐变 + 光柱，不含立绘）
- `assets/bg/01.webp` … `05.webp` —— **轮播立绘**，游戏每 30 秒换一张（间隔在 `src/config.js` 的 `bg.intervalMs`）
  想加/换立绘：丢文件进 `assets/bg/`，再把文件名写进 `config.js` 的 `bg.files`（缺的文件会跳过）

## 音乐

- `assets/music/bgm.mp3` —— 循环播放，署名见同目录 `README.md`

## 三个建议

1. **正方形、透明底**（WebP 或 PNG 都行），主体居中
2. 文件名严格两位编号，**别用中文名**、别加前缀
3. 换完图记得重算碰撞轮廓：`python tools/build-shapes.py`（否则刚体还是旧图的形状）

## 想改名字/大小/颜色

改 `src/config.js` 的 `tiers`：`key`（对应文件名）、`name`（占位鱼上写的字、结算里也用）、`r`（半径）、`ring`（轮廓识别色）、`color`（占位鱼配色）。
