# 素材放这里

## 鱼（必须按编号命名）

放在 `assets/fish/` 下，**两位编号 + `.png`**：

| 文件 | 等级 | 名字 | 说明 | 建议尺寸 |
|---|---|---|---|---|
| `00.png` | 0 | 鱼子 | 最小，最先掉落 | 128 |
| `01.png` | 1 | 小鱼苗 | | 128 |
| `02.png` | 2 | 小金鱼 | | 160 |
| `03.png` | 3 | 河豚 | | 160 |
| `04.png` | 4 | 鲳鱼 | 掉落池最大就到这级 | 192 |
| `05.png` | 5 | 鲈鱼 | | 192 |
| `06.png` | 6 | 鲑鱼 | | 224 |
| `07.png` | 7 | 鲨鱼 | | 256 |
| `08.png` | 8 | 鲸鱼 | | 288 |
| `09.png` | 9 | 小鲸鱼娘 | | 320 |
| `10.png` | 10 | 蓝色大肥鱼 | 终级，两条相撞会炸 | 384 |

（尺寸单位是像素，"建议"只是省流量；实际显示大小由 `src/config.js` 里的 `r` 决定，图片会自动缩放并**裁成圆形**。）

## 背景（可选）

`assets/bg.png` —— 有就用（按比例铺满整块画布），没有就用程序画的深海底渐变 + 光柱。

## 三个建议

1. **正方形、透明底 PNG**，主体居中、四周留 8%~12% 空白（因为会被裁成圆）
2. 文件名严格是 `00.png` … `10.png`，**别用中文名**、别加前缀
3. 缺哪张都没关系：缺的继续用**程序画的占位鱼**（圆身 + 眼睛 + 尾巴 + 名字），刷新页面就能看到

## 想改名字/大小/颜色

改 `src/config.js` 的 `tiers`：`key`（对应文件名）、`name`（占位鱼上写的字、结算里也用）、`r`（半径）、`color`（占位鱼配色）。
