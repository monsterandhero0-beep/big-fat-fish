# 合成大肥鱼

「合成大西瓜」的玩法 × 鲸鱼娘皮肤。**纯前端、零外部依赖、双击就能玩**（物理引擎已放在 `vendor/`，离线可用）。

## 开始玩

双击 `index.html`（或拖进浏览器）。

- 移动鼠标 / 手指：瞄准
- 点击 / 空格：放鱼
- `R`：重开 · `M`：开关音乐
- 右侧「合成表」：每一级的图例（等级 / 名字 / 直径 / 掉不掉落）+ 🔊音效、🎵音乐 开关

**规则**：两条**相同**的鱼一碰就合成更高一级；堆到危险线以上**停留超过 2 秒**就结束。合成到「蓝色大肥鱼」后，两条终级相撞会炸 +2048 并消失。每 **2000 分**攒一颗**复活币**，堆爆时可以花它继续。

## 这一版已经有的（框架）

| 模块 | 说明 |
|---|---|
| 物理 | matter.js（`vendor/matter.min.js`），固定步长、防穿墙/穿地板 |
| **形状** | 11 级**各自按图片轮廓造刚体**（alpha 轮廓的凸包，存在 `assets/shapes.js`），**不是圆** |

| 等级 | 11 级：鱼子 → 小鱼苗 → 小金鱼 → 河豚 → 鲳鱼 → 鲈鱼 → 鲑鱼 → 鲨鱼 → 鲸鱼 → 小鲸鱼娘 → **蓝色大肥鱼** |

| **合成表** | 右侧图例：每级编号/名字/直径 + 本级识别色，并标出哪些**在掉落池**里 |
| 交互 | 出手预览 + 虚线瞄准、冷却、键盘/触屏 |
| 表现 | 合成扩散环 + 飘分、危险线闪烁、结束面板、深海底背景 + 立绘侧景 |
| 记录 | 最高分存 localStorage |
| 素材 | **有图贴图、没图画占位鱼**（占位鱼是程序画的圆身+眼睛+尾巴+名字） |
| 自测 | `node test/sim.mjs`（25 项断言：形状刚体 / 合成 / 加分 / 彩蛋 / 稳定 / 判负 / 复活币） |

## 换成你的图（重点）

把图片丢进 `assets/fish/`，文件名就是两位编号：

```
assets/fish/00.png   → 0 级 鱼子
assets/fish/01.png   → 1 级 小鱼苗
...
assets/fish/10.png   → 10 级 蓝色大肥鱼
assets/bg.png        → 背景（可选，按比例铺满）
```

**放进去刷新页面就生效，不用改代码**；缺哪张就继续用占位鱼。图片是**按原样绘制**的（透明的地方就是真实轮廓，不再裁圆），所以建议：
- 正方形、**透明底** PNG，主体居中
- 尺寸 256（小级）～ 512（大级）就够，太大只是徒增加载

> ⚠️ **换了图一定要重算碰撞轮廓**，否则刚体还是旧图的形状：
> ```
> python tools/build-shapes.py     # 重新生成 assets/shapes.js
> ```
> 它按每张图的 alpha 通道取凸包（9~14 个顶点），所以「图片是什么形状，撞起来就是什么形状」。

细节见 [assets/README.md](assets/README.md)。

```
index.html            入口（双击这个）
src/config.js         等级/尺寸/重力/计分/危险线 —— 想调难度改这里

src/render.js         画布渲染（贴图 / 占位鱼 / 特效）
src/assets.js         素材加载（缺图自动回落）
src/main.js           启动、主循环、输入、HUD
src/style.css         页面样式
vendor/matter.min.js  物理引擎（npm matter-js 0.20.0）
assets/fish/          11 级贴图
assets/bg/            背景立绘（每 30 秒轮一张）
assets/bg.png         背景底图（深海渐变，不含立绘）
assets/music/bgm.mp3  背景音乐（循环）
test/sim.mjs          无头自测
```

## 背景立绘轮播

背景分两层：`assets/bg.png` 是**底图**（深海渐变+光柱），`assets/bg/` 里放**透明立绘**，游戏每 **30 秒**换一张，带 1.4 秒交叉淡入。

想换/加立绘：把透明底 PNG 或 WebP 丢进 `assets/bg/`，再把文件名写进 `src/config.js` 的 `bg.files` ✓（缺的文件会跳过，不会报错）。

## 调参速查（`src/config.js`）

| 想改什么 | 改哪个 |
|---|---|
| 罐子大小 | `width` / `height` / `margin` |
| 难度（能丢哪几级） | `dropTiers`（现在 0~4） |
| 重力手感 | `gravity`（1.0，越大越快） |
| **弹不弹** | `physics.restitution`（0.58，越大越弹） |
| **滑不滑 / 转得动** | `physics.friction` / `frictionStatic`（越小越滑） |
| 太重/太轻 | `physics.density`（0.0012） |
| **复活币门槛** | `coinEvery`（2000 分一颗） |
| **碰撞体积缩放** | `shapeScale`（2.06，要和渲染的 2.06 一致，改大了会"胖一圈"） |
| 危险线高低 | `dangerY`（现在 156，越大越宽松） |
| 结束宽限 | `overStayMs`（现在 2000ms） |
| 计分 | `score` 数组 / `finalBonus` |
| 出手冷却 | `dropCooldownMs` |
| **立绘多久换一张** | `bg.intervalMs`（30000ms）· 淡入时长 `bg.fadeMs` · 透明度 `bg.opacity`（0.46） |
| **音乐/音效音量** | `audio.bgmVolume`（0.38）/ `audio.sfxVolume`（0.55）—— 页面里也有滑条 |
